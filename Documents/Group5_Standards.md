# Group 5 Project Standards

---

## 1. Work Item Naming (Epics, Features, Stories, Spikes)

- **Epic**: `EPIC - [Module Name]`
  - 

- **Feature**: `FEAT - [Your Name] - [Feature Description]`
  -

- **User Story**: `US - [What the user does]`
  - 

- **Spike**: `SPIKE - [Research topic]`
  - 

---

## 2. Git Branch Naming Convention

- `feature/[your-name]/[feature-name]`
- `bugfix/[your-name]/[bug-description]`
- `spike/[your-name]/[research-topic]`

---

## 3. Work Item Attributes

- Assign to correct **Sprint**
- Link to the proper **Feature or Epic**
- Set **Tags** (e.g., Frontend, Backend, Spike)
